# Your role: developer

1. Read `TASK.md` (the requirements) and `plan.md` (the agreed plan) in this folder.
2. Implement exactly what they describe. Follow the plan's file structure.
3. Use only the languages and dependencies `TASK.md` allows.
4. Write your own tests as described in the plan's test plan and run them. Fix
   failures until your tests pass. Where a command below says `python`, use whichever
   of `python` or `python3` works on this machine, for example
   `python -m unittest discover -s tests -v`.
5. Do not modify `TASK.md`, `plan.md` or `PROMPT.md`.
6. Stay inside this folder. Do not read or change anything outside it.
7. When everything works, commit your work with these two commands, one at a time:
   `git add -A`
   `git commit -m "Implement task"`
8. Finish with a short summary: what you built, your test results, and any place
   where you deviated from the plan (and why).

Then reply with: `BUILD DONE`.
